## 1. 新的 AI 開發技術棧 / 框架

- **OpenAI 正式開放「Agents API」公開測試版,把 Codex 背後的 agent 執行環境包裝成單一 API**:新 API 提供 Agent(模型、指令、工具與 MCP 伺服器設定)、可選的沙盒執行環境(Environment)、具持久性的 Session,以及事件串流四大元件,內建程式碼沙盒執行、檔案編輯、MCP 連線、產出物生成與多代理人委派等功能,亦支援企業自架沙盒環境;開發者也可透過 Cloudflare、DigitalOcean、Oracle 等合作夥伴的基礎設施部署代理人。公開測試版對所有開發者開放,不額外收費,僅按實際使用的 token 與工具用量計費。[OpenAI 官方公告](https://openai.com/index/introducing-the-agents-api/) / [MarkTechPost](https://www.marktechpost.com/2026/09/10/openai-launches-the-agents-api-in-public-beta-putting-the-codex-harness-behind-one-api-call/)

## 4. 值得注意的開源模型 / 專案

- **DeepSeek 開源發布 DeepSeek-V4.1-Flash,號稱效能與成本雙雙超越自家旗艦 V4-Pro**:採用新架構家族中最小的模型規格,為 5,520 億參數的 MoE 模型(較前代 V4-Flash 的 2,840 億參數近乎翻倍),原生支援多模態視覺理解;官方引述多方測試指出其在效能、成本、速度與總執行時間上皆優於規模更大的 V4-Pro。DeepSeek 宣布自 9/14 起,原本透過 API 呼叫 V4-Pro 的請求將自動改由 V4.1-Flash 回應,並以較低的 Flash 版計費,直到 V4.1-Pro 推出為止。[SiliconANGLE](https://siliconangle.com/2026/09/10/deepseek-releases-v4-1-flash-says-it-outperforms-flagship-v4-pro/) / [Bloomberg](https://www.bloomberg.com/news/articles/2026-09-10/deepseek-s-new-low-cost-model-deals-a-fresh-blow-to-openai-z-ai)
