## 2. 新的 AI Skills / Agent Skills / Tools
- **HKUDS/CLI-Anything**:香港大學 HKUDS 的開源專案,可以替 GIMP 這類 GUI 軟體自動產生結構化的 CLI,讓 coding agent 直接操作這些軟體。可以當 Claude Code plugin 安裝,也支援 Codex、OpenCode;另外有 CLI-Hub 可以找社群做好的 CLI。這不是新專案,不過今天又上了 GitHub Trending,約 6.4 萬星、單日多了約 790 星。授權寫法不一致(LICENSE 檔是 Apache-2.0,README 寫 MIT),要用之前請自己確認。 https://github.com/HKUDS/CLI-Anything
- **mjmirza/app-store-compliance**:送審 App Store / Google Play 之前用的檢查清單和預檢 playbook,目的是減少被退件。今天上 GitHub Trending,約 5.1k 星、單日多了約 760 星。 https://github.com/mjmirza/app-store-compliance

## 3. AI 大公司重大發表
- **Anthropic 推出 Claude Ship(11/23)**:一組處理 GitHub pull request 的 agents,包含三個部分。Code Review 已經 GA,會深入審查 PR、先自我驗證找到的問題再貼出來;PR Steward(beta)會處理 CI 失敗、merge conflict 和 review 意見,推修正上去,但設計上不會自己 approve 或 merge;Claude Approvals(beta)會照團隊寫在 `.claude/approvals.yml` 的政策,讓 Claude 自動核准例行的變更,風險高的仍然要人簽核。Claude Code 也多了 `/ship` 和 `/steward` 指令。目前只開放 Team 和 Enterprise 方案,使用 ZDR、HIPAA 或客戶自管金鑰的組織不能用。費用是另外按 token 計價,符合資格的 Enterprise 組織在 2027/1/15 前可以領至少 1 萬美元額度。官方建議 Approvals 先開「只觀察」模式。 https://claude.com/resources/articles/introducing-claude-ship (文件:https://code.claude.com/docs/en/claude-ship ;報導:https://siliconangle.com/2026/11/23/anthropics-claude-ship-automates-the-final-stage-of-the-software-development-pipeline/ )

## 4. 值得注意的開源模型 / 專案
- **AWS Strands Decider v2(11/23)**:AWS Strands Labs 推出的「決策模型」第二版。它不負責產生文字,而是從你給的選項裡挑一個並附上可信度,適合 agent 用來做路由或工具選擇這類快速判斷。有 E2B、E4B、12B、26B-A4B、31B 五種大小,都是以 Gemma 4 為基礎、Apache-2.0 授權,權重放在 Hugging Face(`StrandsAgents/strands-decider-*-gemma4-v2-2611`)。訓練資料從 v1 的 13.6 萬筆增加到 1,750 萬筆,不過 benchmark 都是團隊自己測的。 https://strandsagents.com/blog/introducing-strands-decider-v2/ (報導:https://www.unite.ai/aws-releases-strands-decider-v2-and-sandboxes-more-coding-agents/ )
- **MemTensor 開源 MemT-1.0-Pro(11/23–24)**:記憶張量和 NVIDIA 一起做的「memory-native」模型,以 Nemotron-3-Ultra-550B-A55B 為骨幹,在 12 層 attention 裡加了可訓練的記憶模組。總參數 554B、啟用 59B,權重在 Hugging Face,可以用 vLLM、SGLang、Transformers 跑。官方說它在 11 個記憶類 benchmark 上平均 53.08 分,是他們比較過的 parametric-memory 方法裡最高的(這是自家測試)。授權在 HF 上寫 OpenMDW-1.1,但論文頁寫的是 CC BY-NC-SA 4.0,商用前請確認。 https://huggingface.co/MemTensor/MemT-1.0-Pro (新聞稿:https://www.prnewswire.com/news-releases/memtensor-releases-and-open-sources-memt-1-0-pro-a-554b-memory-native-model-302948905.html )
