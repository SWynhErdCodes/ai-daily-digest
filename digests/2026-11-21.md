## 2. 新的 AI Skills / Agent Skills / Tools
- **elementalsouls/Claude-BugHunter**:給 Claude Code 用的漏洞獵捕 skill 包,有 80 多個 skills 和 15 個 slash commands,內容整理自 681 份公開的 HackerOne 報告;另外附送出報告前的檢查清單和 Burp MCP 整合。README 寫明只能用在有授權的目標上。今天 GitHub Trending 第一名,單日多了約 1.6k 星。程式碼是 MIT 授權,文件內容是 CC BY 4.0。 https://github.com/elementalsouls/Claude-BugHunter
- **google-labs-code/stitch-skills**:Google Labs 官方出的 agent skills,搭配 Stitch MCP server 使用,可以從程式碼生成設計稿、萃取 design system,也可以把設計轉成 React、React Native、shadcn 元件。Claude Code、Codex、Gemini CLI、Cursor 都能用,Apache-2.0 授權,約 11k 星。 https://github.com/google-labs-code/stitch-skills
- **Tracer-Cloud/opensre**:開源的 CI/CD 維運 agent(還在 public alpha)。它會讀失敗的 CI run、判斷是 CI 本身的問題還是程式碼的問題,再推一個修正讓你審;可以自架、用自己的模型(支援 Anthropic、OpenAI、Ollama、Bedrock 等)。Apache 2.0 授權,約 13.7k 星。 https://github.com/Tracer-Cloud/opensre

## 3. AI 大公司重大發表
- **Anthropic 公告 IPO 完成交割(11/20)**:承銷商全額行使超額配售權,IPO 總共賣出約 11.27 億股、每股 $83,募得約 935 億美元。另外 AMD、Broadcom、Google、Micron、Microsoft、NVIDIA 和 TSMC 一起透過私募買了約 260 億美元的 Class N 股票,兩邊加起來募資總額約 1,195 億美元。 https://www.anthropic.com/news/ipo-close
- **OpenAI 新版使用政策 11/20 生效**:如果是轉售模型存取權給第三方的 AI gateway 或 model router,現在要先拿到 OpenAI 核准;只是用 OpenAI 模型做自家功能的 app 不受影響。不過根據報導,目前還沒有公布申請管道和審核標準,做 LLM gateway 的人要多留意。 https://openai.com/policies/usage-policies/ (報導:https://www.eweek.com/news/openai-ai-gateway-approval-rules/)
- **Gemini 關掉紀錄後的對話保留期,從 72 小時改成約兩個月**:Google 把「記錄」和「拿來訓練 AI」拆成兩個開關,但就算紀錄關掉,對話也會保留大約兩個月(原本是 72 小時),會在未來幾週陸續套用到全球,在意隱私的人要注意。 https://gizmodo.com/google-to-keep-ai-chat-logs-for-two-months-even-with-gemini-history-turned-off-2000841271 (另見 https://9to5google.com/?p=737886)
