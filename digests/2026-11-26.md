## 2. 新的 AI Skills / Agent Skills / Tools
- **Cognition 推出 SWE-2.1(11/24,補報)**:這是 Devin 內建 coding 模型的新版,跟上一版一樣是在 Moonshot 開源的 Kimi K3 上用純強化學習訓練。官方說 Terminal-Bench 4.1 從 24.2 進步到 50.0、FrontierCode 2.0 從 24.1 進步到 41.3,不過分數都是自家測的,而且整體仍落後 Opus 5.5。另外有跑在 Cerebras 上、號稱快 10 倍的 Lightning 版,以及給 Devin Security 客戶用、限制比較少的 Cyber 版。只能在 Devin 裡用,沒有 API 也沒有開放權重;Desktop 和 CLI 的付費方案到 12/8 前免費。 https://docs.devin.ai/desktop/models (官方公告:https://x.com/cognition/status/2125305349414523061 ;報導:https://i10x.ai/news/cognition-swe-2-1-coding-model-kimi-k3-benchmarks-sandbox )

## 3. AI 大公司重大發表
- **Anthropic 工程部落格:Messages API 從 Python 改寫成 Rust(11/25)**:Anthropic 把 Claude API 的核心服務整個改用 Rust 重寫,每個 request 用的 CPU 少了約 70%、記憶體少了 80% 以上,首個 token 的中位延遲也降了約 20%。文章重點在「怎麼驗證改寫沒改壞」:團隊發現原本的整合測試不夠可靠,所以改拿線上 production API 當標準答案,用 shadow traffic 比對兩邊的輸出(只記錄差異出現的位置,不存內容),一致率從約 24% 提高到 99.6%。核心路徑的第一版是 Claude 大約一週寫完的,到 2026 年 5 月合併的程式碼有八成以上出自 Claude,工程師則負責審查修正、擋掉「能通過驗證但不適合上線」的寫法。如果你也在規劃用 agent 做大型改寫,這篇很值得參考。 https://www.anthropic.com/research/migrating-api-to-rust
- **OpenAI:ChatGPT 和 Codex 將共用同一個用量額度(11/24 宣布,12 月實施)**:Plus、Pro、Business 方案從 12 月起,ChatGPT 和 Codex 會改成扣同一個額度,Instant 對話不算在內,合併後的用量可以在 Settings 查看。Free、Go、Enterprise、Edu 目前沒有說要跟進。OpenAI 沒公布額度有多大,已經有使用者擔心額度會用得更快;這次是先試行,收到回饋後才會擴大。目前只查到媒體報導,還沒找到官方 help center 的說明。 https://www.techrepublic.com/article/news-chatgpt-codex-shared-usage-limits/ (報導:https://thenewstack.io/openai-chatgpt-codex-shared-limits/ )
