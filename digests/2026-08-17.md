## 2. 新的 AI Skills / Agent Skills / Tools

- **Stripe 傳出以逾 70 億美元收購 AI 模型路由服務 OpenRouter**:據 Bloomberg 報導,Stripe 已敲定收購協議,金額是 OpenRouter 三個月前(約 82 天前)B 輪融資估值 13 億美元的五倍以上;OpenRouter 提供跨 400+ 模型的統一 API 路由與計價服務,號稱擁有 800 萬全球使用者,此案顯示企業對「AI 模型閘道/路由」這類開發者工具需求快速攀升,惟 Stripe 官方尚未證實。[Bloomberg](https://www.bloomberg.com/news/articles/2026-08-16/stripe-nears-deal-to-buy-ai-firm-openrouter-for-over-7-billion) / [Fortune](https://fortune.com/2026/08/16/stripe-7-billion-deal-ai-firm-openrouter-acquisition/)

## 3. AI 大公司的重大發表

- **DeepSeek 大幅調漲 API 定價,漲幅最高達 1100%**:新價格已於 8/16 UTC 16:00 生效,首度導入「尖峰/離峰」差別定價(尖峰時段 01:00–04:00、06:00–10:00 UTC),V4-Pro 輸出 token 尖峰價格由每百萬 0.87 美元調升至 3.96 美元,快取輸入價格更暴漲逾 10 倍;分析認為此舉反映其算力成本壓力,將促使開發者更精細地評估任務是否適合交給 DeepSeek。[Reuters via Investing.com](https://www.investing.com/news/economy-news/deepseek-raises-api-pricing-for-its-v4-models-4857662)
