## 2. 新的 AI Skills / Agent Skills / Tools
- **OpenAI × Cisco 開源 Shirudo(11/23–24)**:一個以 eBPF 為基礎的 Linux 安全 runtime,讓 agent(例如 Codex)針對還沒修補的漏洞寫出暫時的 eBPF「shield」,不用重開機就能擋住攻擊,幫維運團隊爭取時間測試正式 patch。eBPF 擋不住的漏洞,也可以改 application bytecode 來處理。設計上每個 shield 都要經過人工核准才會部署,shield 還必須簽章。目前仍是 pre-release,正式環境需要打過 shirudo patch 的 kernel 和 TPM 2.0(本機可以用 VM 加軟體 TPM 試玩)。授權 BSD-2-Clause,GitHub 約 1.8k 星。 https://github.com/shirudo-dev/shirudo (Cisco:https://newsroom.cisco.com/c/r/newsroom/en/us/a/y2026/m11/cisco-and-openai-launch-shirudo-a-new-project-to-safeguard-agentic-ai.html ;報導:https://www.theregister.com/security/2026/11/24/cisco-and-openai-pitch-ebpf-kernel-plugins-as-the-way-to-tame-the-patchpocalypse/5311795 )

## 3. AI 大公司重大發表
- **Anthropic:Claude artifact 可以「Install as app」裝成桌面 app(11/24,beta)**:在 Claude for Mac / Windows 裡打開 artifact,從 Share 選單按「Install as app」,就會變成有自己圖示和視窗的桌面 app,不用自己打包、簽章或準備 API key。所有方案都能用,不過 Team 預設開啟,Enterprise 要 owner 手動打開;HIPAA-ready 組織和 hybrid 部署不能用。Docs、Slides、Sheets 類的 artifact 不能安裝。權限分好幾級,最高到「完整電腦存取」,每次更新都要重新授權。Anthropic 不會事先審查這些 app,app 呼叫 Claude 的用量算在你的方案額度裡。 https://claude.com/resources/articles/install-as-app (報導:https://9to5mac.com/2026/11/24/anthropic-just-gave-claude-users-a-new-way-to-make-mac-apps/ )
- **Anthropic 貼出 Claude 寫的 VP ≠ VNP 證明(11/23,補報,尚未經人類驗證)**:Anthropic 在官方 `formal-math` repo 放了一份 Claude 掛名唯一作者、約 70 頁的論文和 Lean 4 形式化,宣稱證明了 Valiant 1979 年提出的猜想 VP ≠ VNP(代數複雜度裡相當於 P ≠ NP 的問題,但這個結果並沒有解決 P vs NP)。Lean 檢查在 11/23 通過,而且還用獨立的 nanoda kernel 再驗一次。不過目前還沒有人類數學家審查過,最大的疑點是那約 98 行的定義(Statement.lean)是否真的對應到學界說的 VP / VNP。 https://github.com/anthropics/formal-math (報導:https://interestingengineering.com/ai-robotics/claude-proves-vp-not-vnp-valiant-conjecture )
- **OpenAI:GPT-6.2 Sol 進入 ChatGPT 一般聊天(11/23,補報)**:之前 GPT-6.2 只在 ChatGPT Work 和 Codex 裡能用,現在推出針對日常對話調校的 Sol 版本,開放給 Plus、Pro、Business、Enterprise(Free 和 Go 沒有)。官方說新版比較能照著詳細指示做,網頁搜尋和看照片細節也比較強。另外,GPT-5.6 Sol 和 GPT-5.6 Terra 會在 12/23 退場,有用到的話要提早準備。 https://9to5mac.com/2026/11/23/chatgpt-expands-gpt-6-2-sol-as-openai-sets-retirement-date-for-two-models/ (報導:https://www.macrumors.com/2026/11/23/openai-gpt-6-2-sol-chatgpt/ )
