## 2. 新的 AI Skills / Agent Skills / Tools

- **資安研究揭露「GitSpawn」漏洞,惡意 Git 專案可在使用者核准前於多款主流 AI coding agent 上執行任意程式碼**:研究人員發現 Claude Code、OpenAI Codex、Cursor、Grok Build、Goose、Hermes Agent、Qwen Code 等工具在背景蒐集專案脈絡時(如自動執行 `git status`/`git diff`),未過濾儲存庫自身的 Git 設定;惡意儲存庫只要在 `core.fsmonitor` 等設定鍵值植入指令,即可在使用者尚未輸入任何提示或點擊核准前,以使用者權限在主機上執行攻擊者指定的命令。OpenAI Codex 與 Cursor 已於回報後修補,但截至發稿仍有 8 項問題中的 4 項未修補,其中包含 Claude Code「ultrareview」指令另一支利用不同設定鍵值的獨立漏洞;目前尚無實際遭利用案例,使用者可執行 `git config --global core.fsmonitor false` 暫時降低風險。[The Hacker News](https://thehackernews.com/2026/09/malicious-git-configs-can-make-claude.html) / [Manifold Security](https://www.manifold.security/blog/ai-coding-agents-git-hijack) / [Cyber Security News](https://cybersecuritynews.com/gitspawn-flaws-execute-code/)
