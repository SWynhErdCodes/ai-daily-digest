## 2. 新的 AI Skills / Agent Skills / Tools
- **GoogleChrome/modern-web-guidance**:Chrome、Edge、Firefox 與 MDN 團隊合作維護的 agent skills,讓 coding agent 改用現代 Web API、避開過時寫法;用 `npx modern-web-guidance@latest install` 安裝,另有 `legacy-scan` 可掃描舊寫法。今日 GitHub Trending 第一(+739 星)。 https://github.com/GoogleChrome/modern-web-guidance-src
- **CopilotKit/OpenBot**:開源的「AI 同事」平台,每個 agent 都配有自己的瀏覽器、檔案和工具。今日 GitHub Trending。 https://github.com/CopilotKit/OpenBot

## 3. AI 大公司重大發表
- **OpenAI 推出 Businesses in ChatGPT(beta,11/10 補報)**:企業可以認領經驗證的 ChatGPT 商家頁面、查看被提及次數,美國電商/線上服務業者還能上架回答顧客問題的 Business Agent,也可當廣告投放。 https://openai.com/index/introducing-businesses-chatgpt/
- **Google Cloud:AlloyDB AI 新增 `ai.classify` / `ai.extract`(11/12,preview)**:直接在 PostgreSQL SQL 裡做文字分類,或從非結構化文字抽出 JSON,不用另外呼叫模型或寫 prompt。 https://cloud.google.com/blog/products/databases/ai-classify-and-ai-extract-functions-in-alloydb-ai
