## 2. 新的 AI Skills / Agent Skills / Tools
- **Claude Interactive Connectors(11/10)**:Asana、Notion、Box 等合作夥伴的 app 可以直接在 Claude 對話旁或全螢幕開啟,Claude 能在同一個頁面或檔案裡直接修改,動作仍需使用者核准;正在 Web 與桌面版逐步開放給所有方案。 https://claude.com/resources/articles/interactive-connectors-full-tool
- **shadcn/improve**:一個 agent skill,先用頂級模型審查整個 codebase、寫出完整的實作計畫,再交給便宜的模型去執行;本身不改原始碼。今日 GitHub Trending。 https://github.com/shadcn/improve
- **vercel-labs/agent-browser**:用 Rust 寫的瀏覽器自動化 CLI,讓 AI agent 透過一行行簡短 shell 指令操作瀏覽器。今日 GitHub Trending。 https://github.com/vercel-labs/agent-browser

## 3. AI 大公司重大發表
- **Anthropic 推出 Claude Whiteboards、Claude Sheets、Claude Data(11/10)**:Whiteboards(beta)是團隊和 Claude 一起腦力激盪的共用白板;Sheets(beta)讓 Claude 建立與編輯含公式、多分頁的共編試算表;Claude Data 正式上線並取代 Claude Dashboards,提供認證指標與即時分享。付費方案可用,Enterprise 方案預設關閉 Whiteboards 和 Sheets。 https://claude.com/resources/articles/sheets-whiteboards-data
