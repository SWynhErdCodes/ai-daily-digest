## 2. 新的 AI Skills / Agent Skills / Tools

- **Claude Code 新增 `--restricted` 沙盒模式**:8/27 發布(v2.1.248),此旗標(或環境變數 `CLAUDE_CODE_RESTRICTED=1`)會移除內建的指令列/程式碼執行工具與 WebFetch(除非於 `--tools` 明確指定)、將檔案工具限制在工作目錄內、拒絕 `bypassPermissions`,並忽略使用者/專案/本機設定檔,適合在較不信任的環境中執行 Agent。[Claude Code Changelog](https://code.claude.com/docs/en/changelog)
- **Claude Code 新增模型切換 Hook 與 Remote Control 即時串流**:8/28 發布(v2.1.251),新增 `PreModelSwitch`/`PostModelSwitch` Hook 事件可攔截模型切換行為,Remote Control 用戶端可即時看到前景 subagent 的工具呼叫串流,並在 `/usage` 與狀態列新增花費上限顯示。[Claude Code Changelog](https://code.claude.com/docs/en/changelog)

## 3. AI 大公司的重大發表

- **Anthropic 正式將「Claude for Teachers」推廣至全美中小學與學區**:8/28 官方發布,學校/學區管理者可將全校教職員整合進單一受管理組織,採用 K-12 條款與學生資料隱私協議,並提供依美國各州學習標準設計的教學技能;於 2027/6/30 前完成申請的合格機構可享一年免費使用,此前該方案已先於 7 月開放個別教師申請。[Claude Blog](https://claude.com/blog/claude-for-teachers-now-available-for-schools-and-districts)
- **傳 NVIDIA 洽談以約 129~130 億美元收購 Hugging Face(尚未正式證實)**:8/27~8/28 多家財經媒體(CNBC、Bloomberg、Forbes)報導 NVIDIA 已就收購 AI 模型託管平台 Hugging Face 進行實質性談判,若成真將是 NVIDIA 史上最大收購案(超越 2020 年 69 億美元收購 Mellanox);CNBC 稱有消息來源證實雙方近期確有相關討論,但 NVIDIA 與 Hugging Face 均尚未正式回應或發布官方聲明,列入僅供留意後續發展。[CNBC](https://www.cnbc.com/2026/08/27/nvidia-hugging-face-acquisition.html) / [Forbes](https://www.forbes.com/sites/siladityaray/2026/08/27/nvidia-has-reportedly-agreed-to-buy-ai-model-hosting-platform-hugging-face-for-13-billion/)

## 4. 值得注意的開源模型 / 專案

- **Hugging Face 與 Pollen Robotics 推出 399 美元開源機器人鴨「Microduck」**:8/27 發布,身高約 25 公分、重不到 800 公克,搭載 15 顆馬達、相機、深度感測器、麥克風與小型光達,主打「開箱即用」的 7 種預訓練行為(行走、站立、踢腳、抓取、溜冰、跌倒後自行站起等),軟體、模擬工具與強化學習訓練堆疊皆開源,預計聖誕節前出貨,目標是讓開發者以低成本實驗物理 AI 與具身智慧。[TechCrunch](https://techcrunch.com/2026/08/27/hugging-face-is-selling-a-cute-399-open-source-duck-robot-microduck/) / [Axios](https://www.axios.com/2026/08/27/hugging-face-debuts-microduck-a-399-robot)
