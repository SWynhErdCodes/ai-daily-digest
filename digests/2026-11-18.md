## 2. 新的 AI Skills / Agent Skills / Tools
- **sybil-solutions/inference-optimisation-skill**:給 Claude Code 等 agent 用的 skill,用來一步步調校本機 LLM 推論速度(decode、speculative decoding、prefill、KV cache、TTFT),每次只改一個變數、跟前後的對照組比較,還要通過長 context 穩定性檢查才算數;附 OpenAI 相容 API 的 benchmark 腳本,MIT 授權。11/16 新建,約 960 星。 https://github.com/sybil-solutions/inference-optimisation-skill
- **erkamyaman/rust-anything**:CLI + MCP server + agent skill,先錄下原本程式(TS/Python/C/Go/Ruby/Java)的實際行為,再讓 Claude Code、Codex 這類 agent 一塊一塊改寫成 Rust,每一步都對照錄下來的行為驗證。MIT 授權,11/16 新建,約 1.7k 星。 https://github.com/erkamyaman/rust-anything
- **Agent 365 新增成本與風險管理(Ignite,預覽)**:Business Analytics 讓主管看 AI 花費跟實際完成的工作,Cost Management 給 IT 做預算預測和優化建議,Dynamic Agent Risk 會持續評估每個 agent 的資安風險。 https://news.microsoft.com/events/ignite/2026/book-of-news/

## 3. AI 大公司重大發表
- **OpenAI 發布 GPT-6.2 Astra 與 GPT-6.2 Sol(11/17)**:Astra 是旗艦款,主打專業工作、coding、科學研究和 computer use;OpenAI 說它在 Agents' Last Exam 比 GPT-6 Astra 高 5.2 個百分點,每個任務的成本卻不到三分之一,API 價格也降了 20%(每百萬 token 輸入 $8、輸出 $40)。Sol 是便宜款,價格維持 $2/$10。兩個模型 ChatGPT Work、Codex 和 API(`gpt-6.2-astra`、`gpt-6.2-sol`)都能用;OpenAI 也說 Astra 是第一個在 Preparedness Framework「AI 自我改進」項目達到 High 等級的對外模型,所以加強了資安相關的防護。Microsoft Foundry 同步上架。 https://www.testingcatalog.com/openai-launches-gpt-6-2-astra-and-sol-on-chatgpt-and-apis/ (官方公告:https://community.openai.com/t/gpt-6-2-astra-and-sol-are-now-available/1417531)
- **Microsoft Ignite 2026 開幕(11/17)**:主軸是「frontier ecosystem」,把 Copilot 定位成工作的作業系統,重點包括 Foundry 上架 GPT-6.2 和 Meta 最新模型、Agent 365 治理工具、Windows 365 for Agents(提供用 MCP 設定的 Cloud PC 給 agent 做 computer use,明年初預覽)。技術細節見第 1、2、5 節。 https://blogs.microsoft.com/blog/2026/11/17/ignite-2026-building-the-frontier-ecosystem/
- **Anthropic IPO 定出價格區間(11/17)**:Anthropic 提交第三版 S-1 修正,預計以每股 $70–78 發行 8.25 億股 A 類股,11/19 在 Nasdaq 掛牌,代號 ANT;CNBC 引述消息人士說最後定價可能高於這個區間。 https://www.cnbc.com/2026/11/17/anthropic-ipo-price.html
