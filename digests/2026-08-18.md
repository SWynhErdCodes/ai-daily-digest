## 1. 新的 AI 開發技術棧 / 框架

- **Cursor 推出內建程式碼託管平台「Origin」,搶在 GitHub 大當機前上線**:8/17 以 Beta 形式對付費用戶開放,將 Git 託管、PR(diff、留言、合併)直接整合進編輯器,使用者可在瀏覽的 repo 中直接向 Cursor 提問、要求修改或推送新分支,無需離開編輯器;巧合的是 Origin 上線約 3.5 小時後 GitHub 便發生影響 API、Actions、Copilot 等服務的全球性大當機,意外凸顯 AI 編碼工具自建基礎設施的時機優勢。[VentureBeat](https://venturebeat.com/infrastructure/cursor-launches-origin-code-hosting-platform-as-github-outage-exposes-opening-in-ai-coding-race) / [Notebookcheck](https://www.notebookcheck.net/Cursor-launches-Origin-a-built-in-GitHub-alternative-on-the-same-day-GitHub-suffers-a-major-outage.1371041.0.html)

## 3. AI 大公司的重大發表

- **OpenAI 據報於 7 月底解散負責評估「災難性風險」的 Preparedness 團隊**:根據《金融時報》調查報導(8/17 見報),該團隊原本專職在模型上線前獨立評估生物、網路安全等重大風險,如今相關職責被拆散、併入各模型開發團隊,失去原有的獨立性;報導並指出倫理主管 Chloé Bakalar、首席未來學家 Josh Achiam、安全主管 Johannes Heidecke 近期相繼離職,延續此前 AGI readiness team、superalignment team 相繼解散的模式。[itechpost](https://www.itechpost.com/articles/237038/20260817/openai-reportedly-disbands-preparedness-team-ai-safety-strategy-shifts.htm) / [Kernel Tech News](https://kernel.news/2026/08/17/openai-disbands-team-assessing-catastrophic-ai-risks/)
- **Anthropic 正式停用舊版 Claude Workbench 與三個實驗性 Prompt API**:截止日為 8/17,platform.claude.com/workbench 舊版存取權限關閉,先前未匯出的已儲存 Prompt、變數與評測設定將永久遺失且無法復原;/v1/experimental/generate_prompt、improve_prompt、templatize_prompt 三個實驗性端點同步停用,官方建議改用新版 Playground(platform.claude.com/playground),但提醒新工具為無狀態設計,不提供舊版的持久化儲存功能。[Claude Platform Docs](https://platform.claude.com/docs/en/release-notes/overview) / [Tech Times](https://www.techtimes.com/articles/324669/20260817/anthropic-kills-claude-workbench-today-saved-prompts-gone-api-pipelines-broken.htm)
