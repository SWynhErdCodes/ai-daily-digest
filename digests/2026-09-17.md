## 2. 新的 AI Skills / Agent Skills / Tools

- **開源專案「Graphify」在 GitHub Trending 暴紅,將整個程式碼庫轉換成可查詢的知識圖譜**:透過 tree-sitter 對原始碼進行本地端、確定性的 AST 解析(支援約 25 種語言),不依賴向量資料庫,並以 `/graphify` skill 形式整合進 Claude Code、Cursor、Codex、Gemini CLI 等多款 AI 開發助理,讓代理人在搜尋檔案前先查詢知識圖譜,藉此降低誤判與幻覺。[GitHub - Graphify-Labs/graphify](https://github.com/Graphify-Labs/graphify)
- **資安研究者釋出「Claude-Red」攻擊性資安 Skills 庫,收錄 58 款供 Claude Skills 系統使用的紅隊技能**:由獨立研究者 Kai Aizen(SnailSploit)打造,涵蓋 SQL 注入、EDR 規避、AD 攻擊、漏洞開發等 13 大類別,標榜供授權紅隊演練、漏洞賞金、資安研究與 CTF 訓練等合法用途使用,近日在 GitHub 上快速走紅。[GitHub - SnailSploit/Claude-Red](https://github.com/SnailSploit/Claude-Red)

## 3. AI 大公司的重大發表

- **Anthropic 將 Claude Cowork 併入一般對話介面,並同步推出 Claude Docs 與 Claude Slides**:官方部落格宣布不再區分「聊天」與「Cowork」兩種介面,改由 Claude 自動判斷該用哪種模式處理請求;同時新增可與 Claude 共同編輯、匯出成 PowerPoint/PDF 的文件與簡報工具 Claude Docs、Claude Slides,Claude Design 也擴大適用於一般對話,率先開放給 Pro 與 Max 方案用戶。[Claude 官方部落格](https://claude.com/blog/cowork-is-now-claude) / [VentureBeat](https://venturebeat.com/technology/anthropic-is-killing-off-cowork-and-folding-it-into-claude-launching-claude-docs-and-claude-slides)
- **OpenAI 正式在 ChatGPT 中試行「贊助代理人」廣告形式,Wayfair、Angi 為首批合作品牌**:使用者點擊廣告後可與品牌專屬的對話代理人互動、詢問細節,再導向品牌官網或客服流程;此互動會與 ChatGPT 原生回答明確區隔標示,目前僅在美國小規模測試,被視為 OpenAI 首次將對話式廣告正式產品化。[GlobeNewswire](https://www.globenewswire.com/news-release/2026/09/16/3363209/0/en/angi-among-first-brands-to-pilot-sponsored-agents-in-chatgpt.html) / [Contentgrip](https://www.contentgrip.com/openai-sponsored-agent-ads/)

## 5. 雲端部署與基礎設施新知

- **AWS 為 SageMaker AI 訓練與處理任務新增「執行個體偏好清單」功能,加速取得 GPU 運算資源**:使用者過去送出任務時只能指定單一執行個體類型、被動等待配額釋出;新功能可一次提供最多 5 種依優先順序排列的執行個體類型,SageMaker 會自動配置第一個有可用容量的選項,並可混搭隨選與 SageMaker Flexible Training Plans 保留容量來源,免除人工重試腳本。[AWS 官方公告](https://aws.amazon.com/about-aws/whats-new/2026/09/amazon-sagemaker-training-processing-instance-pref-lists/)
