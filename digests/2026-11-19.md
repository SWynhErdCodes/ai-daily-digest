## 3. AI 大公司重大發表
- **Google 推出 Gemini 4 Neon(11/18)**:Gemini 4 系列中間那一級,定位在 Carbon 和 Hydrogen 之間;Google 說它有接近 Carbon 的品質、速度快約三倍,主打 coding、分析推理和企業工作流程。1M context、支援文字 / 圖片 / 音訊 / 影片輸入,API 價格每百萬 token 輸入 $3、輸出 $15;Gemini App(AI Pro / Ultra)、Antigravity、Gemini API 付費版和 Gemini 企業版都能用。HN 上 500+ 分。 https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-gemini-4-neon/ (報導:https://9to5google.com/2026/11/18/gemini-4-neon-announcement/)
- **Microsoft AI 在 Ignite 發布七個 MAI 模型(11/17–18)**:主角是 coding 模型 MAI Code 2 和 MAI Code 2 Flash,微軟說 Code 2 的 coding 表現約有 Claude Opus 5.5 的 96%,成本卻只要約 5%(這是用 5 折促銷價算的);已整合進 GitHub Copilot,Flash 版也開放給免費和學生方案,Foundry 上是有限預覽。其他還有 Cyber 2 Flash、Image 2.7、Realtime 1 等。 https://microsoft.ai/news/microsoft-ignite-2026/ (報導:https://www.infoworld.com/article/4250152/microsoft-launches-mai-code-2-models-to-challenge-openai-and-anthropic-in-ai-coding.html)
- **Anthropic IPO 定價每股 $83(11/18)**:比原本 $70–78 的區間還高,總共發行 9.8 億股 A 類股(公司賣約 9.56 億股),募資約 810 億美元,是史上最大的 IPO,估值約 1.5 兆美元;今天(11/19)在 Nasdaq 掛牌,代號 ANT。 https://www.anthropic.com/news/anthropic-prices-initial-public-offering
- **Claude Fable 5.2 解出兩個黑洞物理的公開問題(11/17)**:Anthropic 說模型證明 Hawking-Page 相變在非幾何時空裡也成立,並推導出 modular bootstrap 方法的精確極限,兩個結果都有預印本。 https://www.anthropic.com/research/claude-black-hole-physics
