## 2. 新的 AI Skills / Agent Skills / Tools
- **Claude Managed Agents 可自架(11/12,private beta)**:整套 Managed Agents(harness、sandbox、憑證、session 紀錄)都能跑在企業自己的雲端或地端,API 跟託管版相同,也能自己決定 Claude 請求送往哪裡;要透過 Anthropic 業務窗口申請。 https://claude.com/resources/articles/self-hosted-claude-managed-agents
- **Google Cloud 推出 HPC 用 agent skills(11/14)**:配合 SC26,釋出一批讓 agent 管 HPC 的 skills,包括查配額、比對 Cluster Toolkit 藍圖(部署前要人工核准)、OpenFOAM/GROMACS/AlphaFold 3 等工作負載,以及 Kueue 除錯;放在 Google Skills 與 DeepMind Science Skills 的 GitHub repo。 https://cloud.google.com/blog/topics/hpc/whats-new-in-hpc-and-ai-at-sc26
- **backnotprop/plannotator**:讓你跟 coding agent 一起規劃、在計畫和程式碼上加註解,再把回饋送回 agent 的工作區工具。今日 GitHub Trending。 https://github.com/backnotprop/plannotator

## 3. AI 大公司重大發表
- **Google Gemini 4 Carbon 開放給開發者(11/10,補報)**:10/28 只先開放給資安防禦用途的 Carbon,現在付費開發者可透過 Gemini API / AI Studio 使用,企業版與 Google AI Ultra 也陸續開放;主打長流程 agent 任務與資安。早鳥價每百萬 token 輸入 $2、輸出 $10,到 11/30 為止。 https://blog.google/innovation-and-ai/technology/developers-tools/gemini-4-carbon-developers/
- **Anthropic 推出 Claude Meetings(11/12,beta)**:Claude 會以可見的與會者身分加入視訊會議,可以回答問題、當場做文件或白板、整理筆記與待辦。目前只支援 Google Meet,開放 Team/Enterprise 方案;啟用 ZDR、HIPAA 或客戶自管金鑰的組織暫時不能用。 https://claude.com/resources/articles/claude-meetings
- **Anthropic 推出 Claude for Manufacturing(11/12)**:製造業用的 plugin,內含 17 個 skills,並串接 Autodesk Fusion、Infor、Microsoft 365、Oracle NetSuite,可以用工廠現有的資料草擬報價、品質報告和供應商需求,送出前都要人工核准。Team/Enterprise 方案可用。 https://claude.com/resources/articles/claude-for-manufacturing
