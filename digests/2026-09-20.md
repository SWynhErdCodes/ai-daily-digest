## 2. 新的 AI Skills / Agent Skills / Tools

- **騰訊開源「BrowserSkill」近日於 GitHub Trending 快速竄紅,讓 AI 代理人得以借用使用者已登入的瀏覽器執行任務**:提供 CLI 與瀏覽器擴充套件雙元件,可讓 Claude Code、Cursor 等具備 shell 執行能力的 AI 代理人在獨立可視視窗中操作使用者「已登入狀態」的真實瀏覽器完成任務,不中斷使用者原本的瀏覽工作,藉此避免重複登入或另建無痕瀏覽環境的麻煩;擴充套件 0.3.0 版於 9/16 發布後,近兩日登上 GitHub Trending 榜單。[GitHub - Tencent/BrowserSkill](https://github.com/Tencent/BrowserSkill)

## 3. AI 大公司的重大發表

- **Anthropic 與埃森哲(Accenture)宣布共組「內嵌式評估團隊」,雙方各承諾未來五年至少投入 10 億美元**:9/18 官方公告,由埃森哲旗下 AI 專責部門 Faculty 主導,評估人員將以近似員工的存取權限進駐 Anthropic 內部,得以觀察模型訓練全程、了解開發與部署決策脈絡,並直接與員工對話,執行紅隊測試、對齊評估與安全防護測試;此舉被視為 Anthropic 執行長 Amodei 稍早呼籲業界「放緩前沿模型開發」倡議的具體落地作法之一。[Anthropic 官方部落格](https://www.anthropic.com/news/accenture-embedded-evaluation) / [TechCrunch](https://techcrunch.com/2026/09/18/anthropics-first-embedded-evaluator-is-accenture/)
- **Anthropic 攜手生技新創 Adaptyv Bio 發布 Claude 加速蛋白質設計研究成果,並同步啟動全球最大規模蛋白質設計競賽**:9/18 官方研究部落格指出,Claude 能將開源生物分子建模流程加速約 4 倍、於單一 GPU 節點上完成逾萬 token 規模的預測,先前測試已對 15 個疾病相關標靶中的 14 個成功設計出具活性的蛋白質結合物;雙方並宣布投入最高 100 萬美元 Claude 額度、25 萬美元 Modal 運算額度,並提供逾 5,000 件設計的濕實驗室驗證,競賽將於 9/28 起分五週釋出不同挑戰題目,面向專業設計師到一般大眾等三個組別開放報名。[Anthropic 官方部落格](https://www.anthropic.com/research/claude-uplifts-biomolecular-modeling)
- **OpenAI 發表「澳洲青少年安全藍圖」,提出六大支柱作為青少年 AI 使用防護框架**:9/19 官方部落格發布,內容涵蓋 AI 素養教育、依年齡分級的安全防護機制、隱私保護型年齡驗證、串接真實世界危機支援資源,以及易於使用的家長監控工具等六大方向;此為 OpenAI 針對特定國家市場提出的首份系統性青少年安全政策框架,延續其 8 月起在澳洲推出的「ChatGPT for Teens」青少年專屬體驗。[OpenAI 官方部落格](https://openai.com/index/australian-youth-safety-blueprint/)
