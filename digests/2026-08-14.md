## 2. 新的 AI Skills / Agent Skills / Tools

- **Claude Code 將「Auto Mode」列為新對話預設權限模式**:自 8/14 起,Pro、Max、Team 方案的新工作階段預設開啟 Auto Mode,Claude Code 不再逐步詢問人工核准,只在動作被判定為「不可逆、具破壞性或會影響環境外部系統」時才會中斷等待確認,先前已於 8/9 預告此變更。[TechCrunch](https://techcrunch.com/2026/08/09/anthropic-is-turning-claude-codes-auto-mode-on-by-default/) / [Digital Applied](https://www.digitalapplied.com/blog/claude-code-auto-mode-default-permission-model-shift)

## 3. AI 大公司的重大發表

- **Anthropic 推出「Claude for Government」公開測試版,並將 Claude Code、Claude Cowork 帶入政府部門**:自 8/14 起開放測試,Anthropic 仍為唯一簽約與計費對象,政府機關不需另外洽談雲端服務商合作即可導入,應用程式可透過機關既有 MDM 平台部署,新客戶可於 claude.com/solutions/government 申請存取。[Claude Blog](https://claude.com/blog/bringing-claude-code-and-claude-cowork-to-government)
- **OpenAI 攜手 Cerebras 推出 GPT-5.6 Sol「Ultrafast」加速模式預覽版**:透過 Cerebras 晶片運算,將輸出速度提升至最高 14 倍(每秒可產出約 750 個輸出 token),鎖定事件應變、客服支援、金融市場分析與電商等需要即時反應的場景;目前僅開放小規模客戶預覽,官方表示將隨運算產能提升逐步擴大開放。[OpenAI](https://openai.com/index/previewing-ultrafast/) / [TechCrunch](https://techcrunch.com/2026/08/13/openai-introduces-ultrafast-a-new-mode-that-makes-gpt-5-6-sol-work-at-14x-the-speed/)
