## 2. 新的 AI Skills / Agent Skills / Tools

- **終端機工具 Warp 推出「Factories」封閉測試,打造可版控的 AI Coding Agent 生產線**:8/18 開放封閉測試,讓多個 Coding Agent(相容 Codex、Claude Code 等任意模型/harness)接力完成一張工單的規格撰寫、實作、審查與驗證,並保留人工核可節點;整條流程以版控設定檔定義(可像程式碼一樣審查變更),並整合 Linear、Jira、Slack、Teams,Warp 執行長透露目前公司內部已有 30-35% 的工作交由此類 factory 處理。[Warp Blog](https://www.warp.dev/blog/open-infrastructure-for-building-a-software-factory)

## 3. AI 大公司的重大發表

- **OpenAI 預告新隱私安全機制「Private Safety Processing」,強調零資料保存下仍可偵測濫用**:8/19 官方部落格發布,新增系統可在不讓 OpenAI 員工存取對話內容的前提下,跨多輪互動比對可疑濫用模式(如惡意代理人行為),觸發時僅會回傳「窄範圍訊號」示警,同時重申將持續為符合資格的 API 客戶提供零資料保存(ZDR)保證;技術白皮書預計 9 月釋出,外界解讀此舉意在隱私保護上超越 Anthropic 現行需保留資料紀錄的做法。[OpenAI](https://openai.com/index/offering-zero-data-retention-for-frontier-models/) / [Axios](https://www.axios.com/2026/08/19/openai-previews-zero-retention-safety-system-as-anthropic-requires-data-logs)
