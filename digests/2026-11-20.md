## 1. 新的 AI 開發技術棧 / 框架
- **⚠️ Microsoft `agent-framework` 在 PyPI 被植入惡意版本(11/17)**:1.26.1 和 1.26.2 兩個版本被塞進一個 `.pth` 檔,只要 Python 啟動就會執行(就算沒 import 這個套件也一樣),會偷 Azure、Azure DevOps 和 GitHub Actions 的 token。因為 agent-framework 本身照常安裝、照常運作,所以很難察覺。目前這兩個版本已經被隔離,最後一個乾淨的版本是 1.26.0。建議把版本固定在 1.26.0,檢查機器和 CI 上有沒有 `site-packages/agent_framework_meta.pth`,有裝過的話要輪換相關憑證。 https://www.wiz.io/blog/malicious-version-of-microsofts-agent-framework-published-to-pypi (另見 https://www.endorlabs.com/learn/agent-framework-compromised-software-supply-chain-attack)
- **Microsoft Copilot SDK 2.0(Ignite)**:原本的 GitHub Copilot SDK 改名並推出 2.0,可以在同一個 process 裡同時跑多個 agent session,支援 TypeScript、Python、Go、.NET、Java、Rust 六種語言;Foundry 的 hosted agents 可以直接用它來開發。 https://www.thurrott.com/?p=344006

## 2. 新的 AI Skills / Agent Skills / Tools
- **GitHub Copilot 的 Ignite 更新**:CLI 和 IDE 可以接自己的模型(bring-your-own-model),並附 agent 治理規則,已經 GA;Copilot 也能處理 Azure DevOps repo,從 clone 一路做到 merge,包括本機 code review 和偵測外洩的密鑰;另外還有預覽功能,可以把工作丟給你自己電腦上跑的本機模型。 https://news.microsoft.com/events/ignite/2026/book-of-news/
- **anomalyco/browse**:MCP server 加 Chromium 擴充套件,讓 OpenCode、Claude Code、Cursor 這類 agent 直接用你平常的瀏覽器(你開的分頁、已登入的帳號、裝好的擴充套件都能用)。MIT 授權,約 940 星,11/19 上了 GitHub Trending。 https://github.com/anomalyco/browse
- **EL4CTEO/blender-skills**:把 Blender 的各種操作流程包成 agent skills,Claude Code、Codex、Gemini CLI 都能用,約 2.4k 星,11/19 上了 Trending。 https://github.com/EL4CTEO/blender-skills

## 3. AI 大公司重大發表
- **Anthropic 在 Nasdaq 掛牌(11/19)**:代號 ANT,開盤價約 $111.50,盤中最高到 $115.10,一度讓市值超過 2 兆美元;收盤 $97.17,比 IPO 價 $83 高約 17%。這次募資約 813 億美元,是史上最大的 IPO。 https://www.forbes.com/sites/fionariley/2026/11/19/anthropic-ipo-live-stock-closes-day-at-97-up-more-than-17/
- **Microsoft 發起 AI Transparency Initiative(Ignite)**:找了 40 多個組織一起訂標準,讓企業能稽核 AI agent 用了哪些資料、拿了哪些權限。 https://edtechinnovationhub.com/news/microsoft-enlists-more-than-40-organizations-to-make-ai-agents-easier-to-audit

## 4. 值得注意的開源模型 / 專案
- **Sage S2.1 Flash(Shanghai AI Lab / InternLM,11/15–16,補報)**:大約 320B 參數的 MoE 科學多模態模型,能讀分子、光譜、EEG 等十多種科學資料;權重和程式碼都是 MIT 授權,有 BF16 和 FP8 兩種版本。官方說在 MLE-bench Lite 拿到 90.3 分(這是官方自己的數字,還沒有第三方驗證)。 https://huggingface.co/internlm/Sage-S2.1-Flash (報導:https://letsdatascience.com/news/sage-s21-flash-report-details-320b-scientific-reasoning-mode-08aba148)
