## 3. AI 大公司的重大發表

- **OpenAI 擴大資安研究計畫 Daybreak,推出專用模型 GPT-5.6-Cyber**:因應 AI 輔助網路攻擊日益增加,OpenAI 將 Daybreak 拆成兩級存取——「Daybreak Blue」解除系統層防護供一般防禦團隊掃描漏洞與驗證修補;「Daybreak Red」則開放以 GPT-5.6 Sol 為基礎、專門訓練用於尋找零時差漏洞與撰寫漏洞利用鏈的新模型 GPT-5.6-Cyber,並降低對高風險雙重用途任務的拒答率,官方測試顯示其在進階資安任務上的完成率達 95%(相較一般版僅 1.5~2%)。[OpenAI](https://openai.com/index/expanding-daybreak-as-the-cyber-defense-window-narrows/)
- **Anthropic 公布未發布研究版 Claude 推進黎曼猜想相關數學難題**:團隊要求一個尚未對外釋出的研究版 Claude 嘗試黎曼假設,雖未真正證明該假設,但透過兩個 Claude Code session、60 個 subagent、共 3,100 萬輸出 token,將黎曼 zeta 函數零點滿足假設之比例的已證明下界,從 41.6% 推進到 67.2%,並公開了論文手稿、Lean 4 形式化證明程式碼與完整過程紀錄供外界檢視(尚未經同行評審,且因模型未公開而無法完整重現)。[Anthropic (X)](https://x.com/AnthropicAI/status/2086867246073401655)

## 4. 值得注意的開源模型 / 專案

- **Meta 開源 30B 參數本機代理模型 Muse Glimmer**:以 Apache 2.0 授權於 8/10 釋出,主打離線在單張消費級 GPU 上執行程式撰寫、function calling 與自主代理任務;透過 4-bit 量化將記憶體需求從 55GB 壓縮至 18–20GB,可在 24GB VRAM 內運作,支援 131K context 與百餘種語言,是 Meta 旗艦模型 Muse Spark 的蒸餾版本,延續其近期開源攻勢。[MarkTechPost](https://www.marktechpost.com/2026/08/10/meta-ai-releases-muse-glimmer/)
