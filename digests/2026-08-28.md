## 2. 新的 AI Skills / Agent Skills / Tools

- **Claude Cowork 新增內建瀏覽器,不再需要外部瀏覽器或擴充套件**:8/26 官方發布,桌面版 AI 代理應用程式 Claude Cowork 側邊欄新增內建瀏覽器,任務涉及網站時會在側欄開啟獨立瀏覽器,由 Claude 自行瀏覽、點擊、填表,不會存取使用者自己瀏覽器的資料;先於 Enterprise 方案上線,一週內陸續開放 Pro、Max、Team 方案(macOS/Windows/Linux)。[Claude Blog](https://claude.com/blog/cowork-built-in-browser)
- **Claude Code 新增自動撰寫意見回饋報告功能(SendFeedback)**:8/26 官方發布(v2.1.247),當工具持續失敗、Claude 自行發現犯錯或使用者當面指出問題時,Claude Code 會自動草擬一份意見回饋報告供使用者於 `/feedback` 檢視後送出,亦可透過 `feedbackDrafts` 設定關閉。[Claude Code Changelog](https://code.claude.com/docs/en/changelog)

## 3. AI 大公司的重大發表

- **Anthropic 推出「Model Hardware Standard(MHS)」研究預覽,首度跨足實體世界 AI**:8/27 官方發布,MHS 是讓 AI 代理安全操作實體設備(如顯微鏡、液體處理儀、機械手臂、雷射)的共通介面標準,可將原本需數週至數月的裝置整合工作縮短至數小時甚至數分鐘,使 Agent 能全天候自主執行實驗、即時調整參數,部分情境下還能在無人介入下從硬體錯誤中恢復;現階段先開放給科學研究與先進製造領域的一小群機構試用,未來計畫將標準開源。AWS 將透過 Strands Robots 函式庫提供搭配支援。[Anthropic](https://www.anthropic.com/news/model-hardware-standard-research-preview) / [CNBC](https://www.cnbc.com/2026/08/27/anthropic-pushes-into-physical-world-with-new-standard-to-help-ai-agents-operate-machines.html)
