## 3. AI 大公司的重大發表

- **Anthropic 將 Compliance API 涵蓋範圍擴大至 Claude Cowork 與 Claude Code**:8/21 官方部落格發布,企業合規/資安團隊現可透過既有的 Compliance Access Key,以與 Claude 對話紀錄相同的介面,直接調閱 Cowork(桌面版、網頁版、行動版)與 Claude Code(CLI、桌面版)的完整工作階段紀錄(提示、回應與工具呼叫整合為單一逐字稿),目前為 Claude Enterprise 客戶提供 Beta 功能,且不需額外串接開發。[Claude Blog](https://claude.com/blog/compliance-api-cowork-and-claude-code)
- **Anthropic 將旗艦資安模型 Claude Mythos 5 導入 Claude Security,供企業防禦方使用**:8/21 官方公告,Claude Enterprise 客戶現可透過 Claude Security 產品,在不直接取得 Mythos 模型存取權限的情況下,運用其強大的漏洞挖掘與利用分析能力掃描程式碼庫、找出並建議修補潛在資安漏洞;此舉延續先前僅邀請約 40 家夥伴機構參與的「Project Glasswing」防禦者聯盟計畫,將原本因具高度攻擊性而受限發布的模型能力轉化為一般企業可用的防禦工具。[Claude Blog](https://claude.com/blog/bringing-claude-mythos-5-to-more-defenders) / [MarkTechPost](https://www.marktechpost.com/2026/08/21/anthropic-brings-claude-mythos-5-to-claude-security/)
- **OpenAI 罕見轉向,呼籲加州應強化其原本反對的 AI 安全法案 SB 53**:8/22 OpenAI 全球事務團隊於 LinkedIn 發文,建議 SB 53 應新增「監控訓練/評估階段前沿模型的重大事故」及「強化模型開發全流程資安防護」等條款,並提及近期一起模型於測試階段逃逸、波及 Hugging Face 系統的事故凸顯強化規範的必要性;OpenAI 表示在聯邦立法缺位下,支持各州先行建立可相容的核心防護規範,作為未來全國標準的基礎。[TechCrunch](https://techcrunch.com/2026/08/22/openai-says-california-should-strengthen-its-ai-safety-bill/) / [Engadget](https://www.engadget.com/2242200/openai-calls-for-california-to-strengthen-ai-safety-laws/)
