## 1. 新的 AI 開發技術棧 / 框架

- **NVIDIA 開源 agent 框架 NOOA**：NVIDIA Labs 釋出 NOOA(NVIDIA Object-Oriented Agents),把整個 agent 濃縮成一個 Python class——方法即能力、docstring 即 prompt、型別註記即約束,由 LLM 在執行時補完邏輯。基準測試中,以 253 行程式碼搭配 GPT-5.5 在 SWE-bench Verified 拿下 82.2%,優於 OpenCode(78.6%)、PI(78.2%)等既有框架,並已貢獻給 NVIDIA 主導的 Open Secure AI Alliance。[MarkTechPost](https://www.marktechpost.com/2026/08/07/nvidia-ai-releases-nooa-an-object-oriented-python-framework/)

## 2. 新的 AI Skills / Agent Skills / Tools

- **Anthropic 推出 Inference Hooks(Claude Enterprise)**:新的即時資料外洩防護層,讓每個受管制的 prompt 在真正送進模型前,先經過企業自建的安全伺服器做「允許/拒絕」判斷,涵蓋範圍包含 MCP 連接器、Skills、Plugins 等所有工具呼叫,並支援影子模式與分階段推行,方便合規團隊漸進導入。[Claude Blog](https://claude.com/blog/claude-enterprise-inference-hooks)
- **Claude 全面支援 MCP 2026-07-28 新規範**:此為 MCP 自推出以來最大幅度的一次改版,協定核心從雙向長連線的 stateful 模式改為無狀態的 request/response 模式,方便部署到 serverless/edge 環境;同時強化 OAuth 2.0/OIDC 授權,讓 MCP server 能直接對接企業的 Entra、Okta 等身分系統。Claude 已同步跟進支援。[Claude Blog](https://claude.com/blog/bringing-mcp-2026-07-28-to-claude)

## 3. AI 大公司的重大發表

- **Meta 推出程式碼代理 Muse Code**:由 Muse Spark 1.2 驅動的終端機編碼工具,可將大型任務拆分給多個背景 agent 在各自獨立的 worktree 中並行處理,正面叫陣 Anthropic 的 Claude Code 與 OpenAI 的 Codex;同時推出「貢獻者方案」,以授權訓練資料換取每百萬 token 僅 $0.30 的低價。[TechCrunch](https://techcrunch.com/2026/08/05/meta-launches-muse-code-an-ai-agent-for-large-code-bases/)
- **Google DeepMind 高層大改組**:Sundar Pichai 以內部備忘錄宣布,Demis Hassabis 卸下 DeepMind CEO 職務,轉任董事長並兼任 Alphabet 首席科學家;原 CTO Koray Kavukcuoglu 升任 SVP,接手 DeepMind 日常營運與 Gemini 模型開發;同時 Google 長年 AI 舵手 Jeff Dean 宣布離職創業。此為 Google AI 團隊近年最大幅度的領導層調整。[CNBC](https://www.cnbc.com/2026/08/05/google-chief-scientist-jeff-dean-leaving-company-after-27-years.html)
- **Microsoft 確認 Copilot「超級 App」整併計畫**:CEO Satya Nadella 於 Q4 財報電話會議證實,將把 GitHub Copilot、Copilot Chat、Copilot Cowork 及新推出的自主代理層 AutoPilot 整併進單一應用程式,統一 GitHub 與 Microsoft 365 的登入身分,預計本季(至 10 月底前)推出;同時將裁撤 Copilot Podcasts、Copilot Labs 等表現不佳的功能。[MLQ](https://mlq.ai/news/microsoft-merges-consumer-and-enterprise-copilot-into-single-app-launches-paid-autopilot-agents/)
- **xAI 語音模型 Grok Voice Think Fast 2.0 正式成為預設版本**:8/5 起 `grok-voice-latest` 別名自動切換至 2.0 版,在 Artificial Analysis 的語音品質測試中拿下 82.9% 分,優於前代(75.7%)、GPT-Realtime-2.1(79.1%)與 Gemini 3.1 Flash(69.5%)。[TestingCatalog](https://www.testingcatalog.com/spacexai-launches-grok-voice-think-fast-2-0-on-agent-builder/)
