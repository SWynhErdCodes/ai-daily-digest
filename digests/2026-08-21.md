## 5. 雲端部署與基礎設施新知

- **Amazon Bedrock 擴大 OpenAI 模型 API 支援並新增跨區域推論**:AWS 官方公告(約 8/17-18 生效),Bedrock 上的 OpenAI 模型新增 Responses、Converse、Chat Completions 三種 API 完整支援,並開放 Global 與 Geo 兩種跨區域推論(Cross-Region Inference),企業無需自行管理多區域容量即可取得更高吞吐量與更低延遲的推論服務。[AWS What's New](https://aws.amazon.com/about-aws/whats-new/2026/08/amazon-bedrock-cross-region-openai-v2/)
- **Microsoft Foundry 更新免命名端點模型「GPT-chat-latest」,底層升級至 GPT-5.6 Sol**:8/19 官方技術社群部落格公告,Foundry 上的 GPT-chat-latest 改採 OpenAI GPT-5.6 Sol 為底層,回應更聚焦精簡,並降低日期、數字、來源等事實性細節的錯誤率,開發者無需更換端點即可直接取得最新模型行為改善。[Microsoft Tech Community](https://techcommunity.microsoft.com/blog/azure-ai-foundry-blog/updates-to-gpt-chat-latest-in-microsoft-foundry/4546815)
