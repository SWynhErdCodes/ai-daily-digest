## 2. 新的 AI Skills / Agent Skills / Tools

- **Claude Code 釋出全面更新,強化 MCP/外掛安全與 Remote Control 穩定性**:8/21 官方發布,新增可自訂的 prompt 與 runner 設定(如 keybindingFlavor 可切換 Bash 風格快捷鍵),收緊外掛市集安全機制(新增 headersHelper,可為目錄/同源封存下載動態產生短期授權 header),並修復 MCP v2 連線在伺服器逾時斷線後不斷重新訂閱、Remote Control 跨裝置/跨會談訊息與斷線恢復不穩定等多項問題,同時改善啟動速度並修掉記憶體洩漏與終端機顯示異常。[Claude Code Changelog](https://code.claude.com/docs/en/changelog)

## 3. AI 大公司的重大發表

- **OpenAI 為 ChatGPT macOS 版推出 Apple Messages 整合,可讀取、搜尋並代為傳送 iMessage**:8/20-21 官方發布(僅限 Apple Silicon Mac 上的桌面版 ChatGPT),需使用者手動於 macOS 授予自動化、聯絡人與完整磁碟取用權限,OpenAI 強調功能於本機端執行、不會另建訊息全文索引,且預設每次代發訊息前都會要求使用者確認(可選擇針對單一對話略過確認),但因涉及讀取財務、密碼等高度隱私內容,已引發外界對隱私風險的討論。[9to5Mac](https://9to5mac.com/2026/08/20/chatgpt-update-adds-apple-messages-integration-on-mac/) / [Forbes](https://www.forbes.com/sites/gabrielalinzainescu/2026/08/21/chatgpt-can-now-send-your-imessages---and-test-apples-privacy-brand/)
- **xAI 將「Grok Bot」正式開放測試版之外的用戶使用**:8/21 官方公告,原於 8/11 以封閉測試上線的常駐式 AI 數位隊友「Grok Bot」擴大開放至 SuperGrok Plus、SuperGrok Heavy 及 Cursor Pro+/Ultra/Teams 等付費方案,可跨應用程式、收件匣與工具持續執行實際工作任務。[x.ai News](https://x.ai/news)

## 5. 雲端部署與基礎設施新知

- **Amazon Bedrock AgentCore 在 AWS GovCloud(US-West)新增 Memory、Policy 與 Harness 三大能力**:8/22 AWS 官方公告,Memory 提供 Agent 短期對話上下文與跨會談長期記憶;Policy 讓團隊以自然語言撰寫規則、自動轉換為 Cedar 政策語言,在程式碼之外集中管控 Agent 與工具的互動權限;Harness 則讓開發者只需宣告模型、工具與指令,不必自寫協調邏輯即可透過少量 API 呼叫執行 Agent,AWS 代管環境、運算、記憶、身分與可觀測性,使受監管產業客戶能更快將 Agent 原型推進到生產環境。[AWS What's New](https://aws.amazon.com/about-aws/whats-new/2026/08/agentcore-memory-policy-harness-govcloud/)
